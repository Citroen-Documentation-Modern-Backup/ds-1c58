Figure : e5ap2y2d
[1] pince pour colliers élastiques de durit refroidissement 9029-T.
Figure : e5ap2ygd
[ 2] pige de repose boîte de vitesses 8010-T.A2  (coffret 8010-T).
Figure : e5ap2yhd
[ 3] outil de maintien convertisseur (-).0336  (coffret 8010-T).
Figure : e5am010d
[4] arrêtoir de volant moteur (-).0188.F.
2. Dépose
ATTENTION : Placer le sélecteur de rapport de vitesses (au volant de direction) en position "N"  (moteur tournant).
NOTA : Ne pas vidanger la boîte de vitesses automatique.
Caler le véhicule sur un pont élévateur.
Déposer l’ensemble moteur-boîte de vitesses.
Figure : b2cm004d
Désaccoupler les durits (1) ; À l’aide de l’outil [1].
Figure : b2cm005d
Déposer les vis (2).
Écarter : Le faisceau électrique de la boîte de vitesses.
Figure : b2cm006d
Déposer les écrous (3).
Déconnecter le connecteur  (en " a").
Figure : b2cm007d
Déposer :
  • Les vis (4)
  • Le démarreur
Figure : b2cm008d
Déposer :
  • Les vis (6)
  • L’impacteur de boîte de vitesses ( 5)
Figure : b2cm009d
Déposer :
  • Les 6 vis (7) du convertisseur de couple ; À l’aide de l’outil [5]
  • Les vis inférieures d’accouplement moteur/boîte de vitesses
Figure : b2cm00ad
Élinguer la boîte de vitesses automatique  (en " b").
Maintenir le moteur à l’aide d’un cric et d’une cale élastique.
Déposer les vis (8).
Figure : b2cp472d
Écarter la boîte de vitesses.
Placer l’outil [ 3] sur le pion de centrage du démarreur sur la boîte de vitesses automatique.
Déposer la boîte de vitesses automatique par le dessous du véhicule.
Maintenir le moteur en place.
3. Repose
Figure : b2cp473d
Poser l’outil [2].
IMPERATIF : Maintenir l’outil [ 3] en place.
Figure : b2cm00bd
Précautions avant remontage :
  • Vérifier la présence des bagues de centrage ( 9)
  • Vérifier l’état de la tôle d’entraînement ( 10)
  • Graisser la bague de centrage ( 11)
Approcher la boîte de vitesses automatique et orienter l’outil [ 2] pour le placer dans le trou "c".
Déposer l’outil [3].
ATTENTION : Ne pas déformer la tôle d’entraînement ( 10).
Déposer l’outil [2].
Reposer :
  • Les vis de fixation de la boîte de vitesses sur le moteur ; Serrage à 6 m.daN
  • L’impacteur de boîte de vitesses ( 5)
  • Les vis (6) ; Serrer à 6 m.daN
  • Les vis (7) du convertisseur de couple
Méthode de serrage des vis (7) :
  • Préserrage à 2 m.daN
  • Desserrage angulaire de 100°
  • Serrage à 6 m.daN
Reposer :
  • Le démarreur
  • Les vis (4) ; Serrer à 3,5 m.daN
Connecter le connecteur  (en " a").
Reposer les écrous (3).
Mettre en place : Le faisceau électrique de la boîte de vitesses.
Reposer les vis (2).
Accoupler les durits (1) ; À l’aide de l’outil [1].
Reposer l’ensemble moteur-boîte de vitesses.
Rebrancher la batterie.
Effectuer les opérations suivantes :
  • Une procédure d’initialisation du calculateur de boîte de vitesses (apprentissage)
  • Le contrôle du niveau d’huile de la boîte de vitesses
  • Purger et faire le niveau du circuit de refroidissement
  • Mettre à jour le compteur d’usure d’huile ; À l’aide de l’outil de diagnostic
IMPERATIF : Réaliser les opérations à effectuer après un rebranchement de la batterie .
