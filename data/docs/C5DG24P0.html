  • Les écrous de bras d’essuie-vitre
  • Les bras d’essuie-vitre avant (2) ; À l’aide de l’outil [1]
  • La grille d’auvent (voir opération correspondante)

  • L’écrou (3)
  • L’écrou en "a"

Figure : c4ap1u3d

  • Les écrous (6)
  • Le cache (7)

Déposer les fixations (en "b").
Déconnecter le connecteur "c".
Déposer le mécanisme d’essuie-vitres avant ( 8).
3. Repose
ATTENTION : Vérifier que le moteur est en position arrêt (position arrêt sur le commutateur).
Figure : c5cp0b2d
ATTENTION : Le balai d’essuie-vitre côté conducteur est au-dessus du balai d’essuie-vitre côté passager.
"d" : Sérigraphie sur pare-brise.
"e" : Sérigraphie sur pare-brise.
Véhicules direction à gauche.
Poser :
  • Le bras d’essuie-vitre droit suivant le repère de sérigraphie en "e"
  • Le bras d’essuie-vitre gauche suivant le repère de sérigraphie en "d"
Véhicules direction à droite.
Poser :
  • Le bras d’essuie-vitre droit suivant le repère de sérigraphie en "d"
  • Le bras d’essuie-vitre gauche suivant le repère de sérigraphie en "e"
ATTENTION : Avant le serrage des bras-balais, faire fonctionner l’essuie-vitre ; mettre la commande d’essuie-vitre en position arrêt et positionner les bras-balais correctement.
Procéder dans l’ordre inverse des opérations de dépose.
Serrer :
  • Les fixations en "b" ; Serrer à 1 ± 0,2 m.daN
  • Les écrous de bras d’essuie-vitre ; Serrer à 2,5 ± 0,3 m.daN
En cas de remplacement, effectuer le télécodage (type véhicule, type conduite) de l’essuie-vitre avant À l’aide de l’outil de diagnostic .
Vérifier le bon fonctionnement électrique des équipements.
