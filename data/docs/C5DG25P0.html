C5DG25P0Dépose - repose : Mécanisme d’essuie-vitre arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
Figure : e5ap38hd
[1] extracteur de bras d’essuie-vitres (-).1371.C.
2. Opération préliminaire
Déshabiller partiellement le volet arrière  (voir opération correspondante).
3. Dépose
Figure : c5dp09bd
Déclipper le cache (1) (en "a").
Pousser sur la languette (en "a").
Déposer le bras d’essuie-vitre arrière ; À l’aide de l’outil [1].
3.1. Volet à vitre fixe
Figure : c5dp09cd
Déconnecter le connecteur "/" (en "b").
Percer les rivets en "c" ; À l’aide d’un foret Ø 8 mm.
Déposer le moteur essuie-vitre (2).
3.2. Volet à vitre mobile
Figure : c5dp09dd
Déposer :
  • Les écrous  (en "d")
  • Le palier (3)
Figure : c5dp09ed
Déconnecter le connecteur "e".
Déposer :
  • Les écrous  (en "f")
  • Le moteur d’essuie-vitre arrière (4)
4. Repose
ATTENTION : Procéder au réglage du mécanisme d’essuie-vitre arrière (voir opération correspondante).
Procéder dans l’ordre inverse des opérations de dépose.
Serrer les écrous à 0,8 m.daN (en "f").
