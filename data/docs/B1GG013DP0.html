B1GG013DP0Dépose - Repose : Radiateur de refroidissement moteur
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Placer le véhicule sur un pont élévateur à 2 colonnes.
Débrancher la batterie .
Vidanger le circuit de refroidissement.
Figure : b1bm19md
Déposer :
  • Le déflecteur (5)
  • Le résonateur d’entrée d’air (4)
  • Les colliers (/) (en "a", "b")
Désaccoupler :
  • La durit inférieure (2) de radiateur de refroidissement
  • La durit supérieure (3) du radiateur de refroidissement
  • Le tuyau de dégazage (1)
Déposer :
  • La cloison antirecyclage (6)
  • Le déflecteur (7)
Figure : b1gm0bqd
Déposer les vis (8) ; À l’aide d’un tournevis (en "c").
Figure : b1gm0brd
ATTENTION : Ne pas détériorer les ailettes du radiateur de refroidissement.
Soulever le radiateur de refroidissement moteur (9) pour le dégager de ses fixations inférieures.
Déposer :
  • Les brides de maintien (10)
  • Le radiateur de refroidissement moteur (9) (suivant flèche ) (Avec précaution)
2. Repose
NOTA : Vérifier la présence des bagues caoutchouc inférieures sur la cassette de refroidissement.
Positionner le radiateur de refroidissement dans la cassette de refroidissement (9).
Reposer :
  • Les brides de maintien (10)
  • Les vis (8)
  • Le déflecteur (7)
  • La cloison antirecyclage (6)
Accoupler :
  • La durit supérieure (3) du radiateur de refroidissement
  • La durit inférieure (2) de radiateur de refroidissement
  • Le tuyau de dégazage (1)
NOTA : Remplacer les colliers déposés par des colliers neufs (en "a", "b").
Reposer :
  • Le résonateur d’entrée d’air (4)
  • Le déflecteur (5)
Remplir et purger le circuit de refroidissement.
Contrôler l’étanchéité du circuit de refroidissement.
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Rebrancher la batterie.
