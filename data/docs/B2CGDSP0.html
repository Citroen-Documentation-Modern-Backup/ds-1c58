2. Dépose
Mettre le véhicule sur un pont élévateur.
Débrancher la batterie .
NOTA : Ne pas vidanger la boîte de vitesses.
Figure : b2cp4jqd
Déposer :
  • Le cache-style batterie (1)
  • Le boîtier filtre à air (2)
Figure : b2cp4jrd
Déposer :
  • La batterie (3)
  • Le support batterie (4)
Figure : b2cp4k3d
Désaccoupler la rotule de commande de sélection (5) du levier de commande de sélection de vitesses (6), en appuyant en "a".
Déposer vis (7).
Écarter la durit ( 8).
ATTENTION : Ne pas déformer le levier de sélection sur la boîte de vitesses automatique (6).
Déposer le levier de commande de sélection de vitesses (6).
Figure : b2cp4k4d

  • Le contacteur de position du levier de sélection (11)

Effectuer une empreinte dans le joint ( 12) ; À l’aide de l’outil [1].
Déposer le joint ( 12) en vissant l’outil [2] dans l’empreinte.
3. Repose
Figure : b2cp4k6d
Nettoyer la portée du joint ( 12).
Reposer :
  • Le joint (12) (neuf) ; À l’aide de l’outil [3]
  • Le contacteur de position du levier de sélection (11) (Serrer légèrement les vis (10) de façon à pouvoir tourner le contacteur de position )
  • Le levier de sélection de vitesses (6)
  • Le connecteur 12 voies vert "c" dans le connecteur modulaire "b"
  • Le capotage du connecteur modulaire "c"
  • Les vis (9) ; Serrer à 1 ± 0,1 m.daN
Figure : b2cp4k7d
Placer le levier de sélection en position "Neutre".
ATTENTION : Ne pas utiliser de lampe témoin car le contact ne supporte que 100 mA maximum.
Brancher un ohmmètre entre les 2 fiches de réglage du contacteur (11) (suivant flèches).
Réglage du contacteur de position (11) :
  • Définir le secteur de réglage du contacteur (11) dans lequel la résistance R = 0, en tournant le contacteur (11) dans un sens puis dans l’autre
  • Positionner le contacteur (11) au milieu du secteur de réglage défini
ATTENTION : Vérifier le réglage après serrage.
Serrer les vis (10) à 1,5 ± 0,2 m.daN.
ATTENTION : Maintenir le levier de sélection de vitesses ( 6) pour accoupler la rotule de commande de sélection (5).
Serrer la vis du levier de sélection de vitesses ( 6) à 1,5 ± 0,2 m.daN.
Repositionner la durit ( 8).
Reposer :
  • La vis (7)
  • Le support (4)
  • La batterie (3)
  • Le boîtier filtre à air (2)
  • Le cache-style (1)
Rebrancher la batterie.
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie (voir opération correspondante).
ATTENTION : Vérifier le fonctionnement de la commande de sélection dans toutes les positions.
