C4EB5DP0Identification : Inserts gonflants
1. Introduction
Les caisses sont livrées avec des inserts gonflants.
Lors de l’échange sur le véhicule d’un élément comprenant un insert gonflant, le réparateur doit effectuer les opérations suivantes.
1.1. Première méthode
Positionner l’insert gonflant dans l’élément.
Faire une injection de mousse polyuréthane " C6".
1.2. Deuxième méthode
Positionner l’insert gonflant dans l’élément.
Faire un joint d’étanchéité sur le pourtour de l’insert gonflant avec un produit d’étanchéité indice "A1".
NOTA : Un insert gonflant d’origine ne s’expanse qu’à une température de 165 °C.
