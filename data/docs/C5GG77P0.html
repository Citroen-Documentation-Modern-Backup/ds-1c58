C5GG77P0Dépose - repose : Garniture de pavillon
SANS VITRE PAVILLON
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Outillage préconisé
Figure : e5ap30wd
[ 1] Outils de dégarnissage (-).1350-ZZ.
2. Dépose
Avancer les sièges avant en position maximum .
Mettre les sièges avant en position allongée.
Rabattre les dossiers de sièges arrière.
Déposer (voir opération correspondante) :
  • Les garnitures supérieures de pied arrière
  • Les garnitures de montant de baie
  • Les enjoliveurs du module pare-soleil
  • Le joint de coffre (partiellement)
Figure : c5gp0smd
Déclipper les éclaireurs de pavillon (1) ; À l’aide de l’outil [1] (suivant équipement).
Déconnecter les connecteurs des éclaireurs de pavillon (1).
Déposer les éclaireurs de pavillon (1).
Déclipper les caches de pavillon (2) ; À l’aide de l’outil [1].
Déposer les caches de pavillon (2).
Déclipper l’enjoliveur de ceinture de sécurité (3) ; À l’aide de l’outil [1].
Déposer l’enjoliveur de ceinture de sécurité (3).
Figure : c5gp0snd
Abaisser la poignée de maintien ( 4).
Déclipper les caches articulés ( 5) ; À l’aide d’un petit tournevis.
Déposer :
  • Les vis (6)
  • La poignée de maintien (4)
Procéder à l’identique pour les autres poignées de maintien.
Figure : c5gp0spd
Déconnecter le connecteur (en "a").
Décoller la garniture de pavillon (7) (en "b") ; À l’aide d’une spatule.
Déposer la garniture de pavillon ( 7) en la sortant par l’arrière du véhicule.
3. Repose
Appliquer les cordons de mastic A3 sur les zones de collage (en "b").
NOTA : Deux personnes sont nécessaires pour effectuer l’opération suivante.
Procéder dans l’ordre inverse des opérations de dépose.
NOTA : En cas de détérioration ou marquage, remplacer systématiquement la garniture de pavillon.
Vérifier le bon fonctionnement électrique des équipements.
